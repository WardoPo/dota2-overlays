# DOTA2 Streaming Overlays

## How to run

1. Write your Steam API Key into a file named "API KEY" in the `/stream_web_api` folder
2. Install packages `npm install`
3. Run the server `npm start`
4. Enter the steam_server_id at `/site/config.html`
5. Get the overlays from:

| Overlay | URL              |
|---------|------------------|
| Draft   | /site/draft.html |
